# Project template for Node.js/npm based TS development

This project is intended to be used as a starter project template.

## Initializing the project

Run `npm install` to install the necessary modules.

## Running your code

Run `npm run build` to build all ts files into the folder `dist`.
Run `npm start` to execute your js code with node.

## Debugging your code

- set breakpoints to make your program stop at interesting TS code lines 
- build the project with `npm run build`
- open a Java Script Debug Console in VS Code and cd into the project
- run `npm start`, execution should stop at the first breakpoint
